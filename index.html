Questions.

Why a path instead of the image? +

Terminal agents like Claude Code and Codex read files by path, not pasted pixels. PromptShot hands them the exact path so you skip the part that always breaks.

Does anything get uploaded? +

No. No account, no server. Screenshots save to your own disk and the path is a local file path. PromptShot has no host access to the pages you visit.

Which browsers work? +

Any Chromium browser: Chrome, Edge, Brave, and Arc. It is a standard Manifest V3 extension.
